这是 `xfy-see/mosdns` 的 Go 优化首版，基于上游 v5.3.4 后续代码，保留 `coremain/pkg/plugin` 分层及 sequence 配置设计，提供 Linux ARM64 与 amd64 的 full/minimal 两种产物。

源码提交：[c203ecd11bd8e8b897789bef8f9798dee80c987b](https://github.com/xfy-see/mosdns/commit/c203ecd11bd8e8b897789bef8f9798dee80c987b)。发布文件直接复用 [GitHub Actions run 37875686901](https://github.com/xfy-see/mosdns/actions/runs/37875686901) 的已校验产物，未重新编译；程序内的版本字符串仍为 `git-c203ecd11bd8e8b897789bef8f9798dee80c987b`。

## 主要改动

- 增加 `mosdns_minimal` 构建版本，两版共用 DNS 请求上下文、内存缓存、域名匹配和 UDP/TCP 处理代码。
- 域名规则使用共享后缀表与分批字符串存储，减少大量规则加载时的节点及字符串分配。
- HTTP/2、gzip 使用 Go 标准库，缓存 dump 使用轻量编码实现并保持 v2 文件格式兼容；减少生产二进制依赖。
- 使用轻量业务指标实现，pprof 改为显式编译标签启用。
- 修复缓存 Qtype 高字节、非 IN 查询缓存隔离、并发过期条目删除、map 清空锁及覆盖条目误淘汰问题；修复请求上下文残留回答、早到 DNS 回答丢失，以及上游连接/socket 生命周期中的资源释放问题。
- 补充兼容性、协议、并发及资源回收回归测试；增加按提交 SHA 构建、记录冻结输入及校验下载文件的 CI 流程。

## 选择产物

| 文件 | 用途 | 大小 |
| --- | --- | ---: |
| `mosdns-minimal-linux-arm64` | ARM64 精简版 | 6,291,582 B（6.00 MiB） |
| `mosdns-full-linux-arm64` | ARM64 完整版 | 14,352,510 B（13.69 MiB） |
| `mosdns-minimal-linux-amd64` | x86-64 精简版 | 6,721,662 B（6.41 MiB） |
| `mosdns-full-linux-amd64` | x86-64 完整版 | 15,450,238 B（14.73 MiB） |

minimal 保留 `domain_set`、`cache`、`forward`、`sequence`、`udp_server`、`tcp_server` 六类插件，支持 `qname`、`has_resp`、`nftset`、内存/lazy cache、数字 IP UDP/TCP 上游及 UDP 截断后的 TCP 回退。它不包含 HTTP API、指标、磁盘 dump、加密 DNS、SOCKS/bootstrap、`ip_set`/`resp_ip` 等完整插件或后台服务安装命令。

full 保留当前分支完整插件集合、HTTP API、指标、磁盘 dump、DoT/DoH/DoH3/DoQ 等功能。两版配置支持 YAML/YML/JSON；full 的轻量指标输出采用 Prometheus text 0.0.4 和 gzip，部分 runtime 指标及自定义 Go 插件指标接口有兼容边界。详见 [版本能力范围](https://github.com/xfy-see/mosdns/blob/c203ecd11bd8e8b897789bef8f9798dee80c987b/docs/go-profiles.md) 与 [指标说明](https://github.com/xfy-see/mosdns/blob/c203ecd11bd8e8b897789bef8f9798dee80c987b/pkg/metrics/README.md)。

两种架构均由 Go 1.26.0 构建，`CGO_ENABLED=0`，不使用 UPX、不启用 pprof；运行时无需另行安装 Go。ARM64 基线为 `GOARM64=v8.0`，amd64 基线为 `GOAMD64=v1`。nftset 功能需要目标系统具备 Linux nftables 和相应权限。

## 验证范围

GitHub Actions 的 full、minimal、full+pprof 三组全项目测试及 full/minimal 两组关键包 race 任务全部成功：full 与 full+pprof 各记录 763 个测试及子测试通过事件，minimal 649 个；race 分别 73 与 52 个。条件不满足的测试按测试规则跳过。ARM64 与 amd64 的四个生产 ELF 均生成成功，下载后已核对提交、构建参数、冻结源码输入、ELF 架构及 SHA-256。

该次 CI 的新 ELF 尚未进行目标 OpenWrt ARM64 设备运行和页面访问性能回归，因此本 Release 不提供这些产物的设备性能提升结论。

## 附件与校验

可以直接下载对应架构的 full 或 minimal 可执行文件，Linux 下载后执行 `chmod +x 文件名`。`mosdns-go-linux-<架构>.tar.gz` 包含两种二进制、构建 manifest、冻结源码快照、依赖图及命令日志；`manifest-linux-<架构>.json` 为独立构建记录，`BUILD-INFO.json` 记录提交及 CI 校验来源。`SHA256SUMS` 校验上述九个附件，可在下载目录执行 `sha256sum -c SHA256SUMS`（macOS 使用 `shasum -a 256 -c SHA256SUMS`）。
